# BSUIR_Savchenko

Контрольная работа № 1. ASP.NET Core MVC.

Требуется .NET 10 SDK.

```bash
dotnet restore BSUIR_Savchenko.sln
dotnet run --project src/BSUIR_Savchenko.UI
```

Откройте локальный адрес из вывода `dotnet run`.

Страницы «Каталог», «Администрирование» и «Корзина» не реализованы, согласно примечанию к заданию. Logout демонстрирует POST-форму, а не полноценную авторизацию.
